# Proyecto de Ingeniería de Software

Repositorio principal para el trabajo en equipo del proyecto de Ingeniería de Software.

## Estructura del Proyecto

- `confidential/` - Carpeta local designada para archivos confidenciales o privados (excluida del control de versiones mediante `.gitignore`).
- `.gitignore` - Reglas de exclusión para evitar subir secretos, dependencias y archivos temporales.

## Colaboradores

Para colaborar en este repositorio:
1. Clonar el repositorio.
2. Crear una rama (`git checkout -b feature/nombre-tarea`).
3. Realizar los cambios y confirmar (`git commit -m "Descripción del cambio"`).
4. Subir la rama (`git push origin feature/nombre-tarea`) y abrir un Pull Request.
